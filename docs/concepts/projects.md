# Projects

Projects group related workloads inside one organization. A project owns environments and provides the top level of inherited variables and secrets.

Use one project for applications that share a product lifecycle and access expectations. Same-project applications attached to one Silicon Network may communicate with that project's services by default. Cross-project private-network traffic requires an explicit same-organization policy.

Project deletion is permission protected and constrained by owned data. Review environments, applications, deployments, domains, and network attachments before deleting a project.
